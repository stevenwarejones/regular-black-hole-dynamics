# Sources

Retrieve and check these independently; no third-party PDFs or code are bundled.
Version tags below are the ones inspected; confirm against current metadata.

## Model origin

1. A. Eichhorn and P. G. S. Fernandes, *Regular black holes without
   mass-inflation instability and gravastars from modified gravity*,
   arXiv:2508.00686v2; Phys. Rev. D 113, L081501 (2026).
   Origin of the action and the static background specialized here. Note: the
   radial-dynamics question studied in this repo is distinct from that paper's
   separate mass-inflation discussion; the two should not be conflated.
   - https://arxiv.org/abs/2508.00686

2. C. Charmousis, P. G. S. Fernandes and M. Hassaine, *Proca theory of
   four-dimensional regularized Gauss–Bonnet gravity and black holes with
   primary hair*, arXiv:2504.13084v2. Underlying vector–tensor construction and
   static vector-hair / norm-family lineage; broad vector-hair ideas predate
   this project.
   - https://arxiv.org/abs/2504.13084

## Close dynamical comparisons (context; not duplicated here)

3. Regular Vaidya solutions in effective spherical theories, arXiv:2506.14875v2.
   Matter-supported *varying-mass* solutions — contrast with the constant-mass
   *vacuum* hair variation claimed here.
   - https://arxiv.org/abs/2506.14875

4. Static-to-Vaidya constructions in scalar–tensor theories, arXiv:2309.03024v2.
   An existing method for obtaining radiating solutions in other theories.
   - https://arxiv.org/abs/2309.03024

5. Dynamical regularization scales (biscalar 2D Horndeski framework),
   arXiv:2609.01733v1. A direct conceptual comparison; "first dynamical
   regulator" is **not** a defensible broad claim.
   - https://arxiv.org/abs/2609.01733

6. Formation of extremal regular black holes, arXiv:2608.02908v1. A recent
   dynamical construction with different theory/source assumptions.
   - https://arxiv.org/abs/2608.02908

## Scope of the comparison

A bounded literature search did not find an exact duplicate of the constant-mass
vacuum `q(v)` family in this specific two-vector action in the inspected corpus.
That is a bounded search result, **not** guaranteed priority. Dynamical regular
black holes, dynamical regularization scales, constant-norm vector hair, and
vector contributions to gravitational charges all have close precedents; none of
those broad ideas is claimed as novel here. This repository does not add a
correction of the source paper's Fourier argument; deferring that comparison is
not the same as resolving it.
