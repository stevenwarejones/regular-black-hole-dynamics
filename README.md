# regular-black-hole-dynamics

Exact time-dependent spherical solutions of a two-vector model of regular black
holes, with machine-checkable certificates.

> **Status.** AI-produced research artifact under adversarial cross-review. Not
> reviewed by a human domain expert. No historical priority claimed.
> See [`docs/PROVENANCE.md`](docs/PROVENANCE.md).

Scaffold only on `main`. The solution, the derivation of the equations of
motion from the action, and the exact-arithmetic certificates are added in the
first pull request. See [`docs/SOURCES.md`](docs/SOURCES.md) for the origin of
the model.
